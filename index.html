🏨 住宿
仙台段住仙台站附近（近半馬起跑），奥州段住水沢江刺 / 一関（近全馬會場）。經濟酒店 / 溫泉旅館混合，雙人房計；實際酒店按情況調整（同等級）。
🚄 交通
全程 東北 JR Pass 10日，新幹線 + 在來線任搭。香港快運 HKG⇄SDJ 直航來回。每程車程約 30 分鐘–2 小時，跑手唔使自己煩交通。
🍱 餐飲
主力自理（跑馬後彈性食），我哋會推薦仙台牛舌、前澤牛、花卷溫泉會席等必食。唔包團餐，慳返你自己揀。
💪 體力
兩場馬拉松夾 5/13 佛誕休腳。半馬控制配速當 long run，主力留返全馬；賽後溫泉恢復。新手 / 有經驗跑手都啱。

FAQ

常見問題

大家都問嘅嘢，一次過答你。

唔識日文 / 第一次跑馬拉松，得唔得？
得。我哋有跑過日本賽事嘅經驗同事全程陪住，報名逐格教你填；到埗後領隊跟進、賽前 briefing。新手或者完全唔識日文都歡迎，你負責跑，其餘我哋搞掂。
報名費包唔包？抽唔中籤點算？
參賽費（仙台 ¥8,000 + 奥州 ¥10,000）直接喺官方俾，唔經我哋手。我哋唔保證名額、唔代辦報名——因為日本賽事唔容許第三方代報名。但我哋會喺官方一開報名就提醒你＋陪你填表，仙台半馬係先到先得，夠快就報到。
團費包唔包機票 / 保險？
團費包 住宿 + JR Pass + 領隊跟進。機票（約 HK$2,800）同保險（約 HK$300）係自己另外俾，我哋可以幫你搵最平航班。保險強烈建議買（包埋運動），詳情睇資訊頁費用分項。
點樣付款？要俾幾多訂金？
付款細節會喺你查詢後同你落實，支援轉數快 / 信用卡等常見方式。訂金比例以當時報價為準，透明列明。
如果賽事 / 疫情取消，點安排？
參賽費係官方收取，賽事取消一般由官方安排退款或順延（以官方公佈為準）。住宿 / 交通部分我哋會盡量幫你彈性安排。建議買旅遊保險保障呢啲情況。
酒店喺邊區？近唔近起跑點？
仙台段住仙台站附近（近半馬起跑點），奥州段住水沢江刺 / 一関一帶（近全馬會場），朝早唔使趕。實際酒店會按情況調整（同等級），以出發前通知為準。
同行屋企人唔跑馬，有冇安排？
有。陪跑親友可以報奥州同日嘅 10km / 1.7km 親子跑，或喺賽事日去 cheer zone 打氣；平時就跟團觀光（松島、平泉、溫泉）。包住宿交通，只係唔包參賽費。
成團人數上限？幾多人先開團？
為咗保持服務質素同「齊人先好玩」嘅氛圍，名額有限。詳細成團 / 人數上限喺你查詢時會同你講清楚。想確保有位，盡早查詢。
