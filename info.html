01報名平台解說（外國人）

日本最大跑步平台 RUNNET 嘅服務只限日本國內居民。海外跑手報名日本馬拉松，主要經以下兩個途徑：

主力平台
🌐 Run Japan（runjapan.jp） —— 前身就係「RUNNET GLOBAL」（2024年11月改名）。全英文/繁中，專為海外跑手而設。
🔗 https://runjapan.jp
📘 RUNNET 官方「For Overseas Participants」指引頁 —— 確認 RUNNET 只限日本居民，並引導海外跑手去 Run Japan。
🔗 https://runnet.jp/runtes/global

Run Japan 外國人報名流程

1
免費註冊 RUNNET JAPAN 會員
runjapan.jp/help/register01.html
2
搜尋賽事（按地區 / 月份 / 距離）
3
揀啱大會 → 按 Entry，填海外跑手資料
4
信用卡付款（海外付款，留意手續費）
5
賽前約1個月收到電郵「參賽指南 + 號碼布兌換券」
⚠️ 唔係每個大會都有開設 Run Japan 海外名額。若 Run Japan 搵唔到，就直接去賽事官方網站查詢海外報名。我哋有經驗人仕幫手報名、跟進流程（唔保證名額、唔代辦）。

組別資格達標紀錄
一般の部Ⅰ18歲以上半馬 < 2:00 或 全馬 < 4:30（2023.12–2025.11 大會）
一般の部Ⅱ18歲以上能喺 2:30 內完成半馬
エリート/陸連陸連登錄者更高設定紀錄

📌 完走證要喺付款後指定日期前 upload（唔交或唔達標會被取消資格）。

📍 資料來源：日本氣象廳 平年值（1991–2020，30年）。仙台為氣象台觀測值；奥州以就近嘅江刺/盛岡測站平年值（江刺 平均最高約21°C、最低約9.8°C）為準。

07b我哋點幫你報名（誠實定位）

先講清楚：我哋唔係官方授權代辦，唔賣名額、唔幫你代報名——因為日本賽事明文唔容許第三方代報名，私下轉讓名額會作廢（東京馬・仙台半馬官方都有寫明）。呢個唔係我哋唔想做，而係守規矩嘅唯一做法。

但我哋有 跑過日本賽事嘅經驗同事,會喺官方通道一步步陪你報名：

1
幫你核對資格——仙台半馬要達標紀錄，幫你睇清楚自己屬邊組
2
提醒你報名開放日——官方一開就通知你，唔會錯過
3
陪你填表——Run Japan 全英文/繁中，逐格教你填
4
付款後跟進——確認信、號碼布兌換、賽前注意，全程盯住

📌 即係：名額你直接喺官方攞，錢你直接俾官方，我哋負責令成個過程唔使自己盲摸摸。
