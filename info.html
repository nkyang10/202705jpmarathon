1報名平台解說（外國人）

日本最大跑步平台 RUNNET 嘅服務只限日本國內居民。海外跑手報名日本馬拉松，主要經以下兩個途徑：

🌐 Run Japan（runjapan.jp） —— 前身就係「RUNNET GLOBAL」（2024年11月改名）。
全英文/繁中平台，專為海外跑手而設，目前約 51,000 會員。RUNTES 引入大會可自動開設海外報名頁。
🔗 https://runjapan.jp
📘 RUNNET 官方「For Overseas Participants」指引頁 —— 確認 RUNNET 只限日本居民，並引導海外跑手去 Run Japan。
🔗 https://runnet.jp/runtes/global

Run Japan 外國人報名流程

1
免費註冊 RUNNET JAPAN 會員
🔗 runjapan.jp/help/register01.html
2
搜尋賽事（Race List 可按地區/月份/距離搜尋）
3
揀啱大會 → 按 Entry，填海外跑手資料
4
信用卡付款（海外付款，留意手續費）
5
賽前約1個月收到電郵「參賽指南 + 號碼布兌換券」
⚠️ 唔係每個大會都有開設 Run Japan 海外名額。若 Run Japan 搵唔到，就要直接去賽事官方網站查詢海外報名，或經官方 ITP（國際旅行代理）／我哋痴LS Group 代辦。

組別資格達標紀錄

一般の部Ⅱ18歲以上能喺 2:30 內完成半馬
エリート/陸連陸連登錄者更高設定紀錄

📌 完走證要喺付款後指定日期前 upload（唔交或唔達標會被取消資格）。

5賽前各項事項 Checklist

  • 報名：兩場賽事確認報名成功 + 付款（海外跑手留意手續費）
  • 完走證 / 達標紀錄：仙台半馬要按期限上載
  • 旅遊保險 + 運動保險：海外傷病醫療費可以好貴，必買（大會保險唔夠cover）
  • 機票：香港快運 HKG⇄SDJ 直航；預設回程 5/16 羽田紅眼
  • 東北 JR Pass 10日：5/8 開始連續用，新幹線+在來線任搭（¥50,000）
  • 住宿：仙台駅周邊（5/8–5/12）+ 奥州/一関（5/14–15），賽前週六要早訂
  • 號碼布：5/8 + 5/15 兩次都要賽前一日去會場領取
  • 裝備：跑鞋、號碼布、能量膠、防曬帽；5月東北可能30°C，注意補水
  • 半馬+全馬相隔7日：半馬當高質素 long run 控制配速，主力留全馬
  • 完賽後：泡花卷溫泉恢復；唔好即刻長途飛，揀紅眼有心理準備
