## 三、逐日行程

### Day 1｜5/8（六）香港 → 仙台
- **UO891 HKG 08:15 → SDJ 13:30**（香港快運直航，~5hr15）
- 仙台機場 → 仙台駅（機場快線 ~25min），酒店 check-in
- 下午：**仙台半馬 報到 / 領取號碼布**（會場：弘進パーク仙台，賽前一日必須領取）
- 夜晚：仙台名物**炭燒牛舌**、毛豆麻糬（ずんだ），**早啲瞓**儲體力
- 🏨 宿：仙台駅周邊（東横INN仙台東口/西口中央，賽前週六要早訂）

### Day 2｜5/9（日）🏁 仙台國際半馬（21.0975km）
- 10:05 第1波浪（精英/一般I）｜10:15 第2波浪（一般II）起跑，限時 2:30
- 賽道：弘進パーク仙台 → 定禅寺通（「杜之都」林蔭大道）→ 卸町 → 折返
- 完賽：仙台城跡/瑞鳳殿打卡、大啖牛舌慶功
- **跑法策略**：呢場當「B 賽事」控制配速（當有質素嘅 long run），主力留返下星期日全馬
- 🏨 宿：仙台

### Day 3｜5/10（一）松島・恢復遊
- **松島**（日本三景）遊船 + 瑞巌寺 + 五大堂
- 輕鬆恢復行，唔好劇烈運動
- 🏨 宿：仙台 或 轉住松島溫泉

### Day 4｜5/11（二）平泉世界遺產
- **平泉 中尊寺・金色堂**（UNESCO）、毛越寺、嚴美溪
- 仙台→平泉 新幹線/在來線（JR Pass 全包）
- 🏨 宿：一ノ関 或 盛岡

### Day 5｜5/12（三）盛岡・花卷溫泉
- **盛岡**：盛岡城跡公園、盛岡冷麵、前澤牛
- 下午 **花卷溫泉** 泡湯，為全馬前深度恢復
- 🏨 宿：花卷溫泉 或 盛岡

### Day 6｜5/13（四）佛誕・全日恢復
- 紅日放假 —— **全日休腳**：溫泉、按摩、輕食補碳
- 大谷翔平出身地周邊走走（奥州/一関）
- 🏨 宿：一ノ関 或 水沢江刺 附近

### Day 7｜5/14（五）轉戰奥州・補碳
- 移動到 奥州市（一ノ関/水沢江刺），酒店 check-in
- **最後補碳日**：多食飯/麵，儲 glycogen
- 🏨 宿：奥州/一関

### Day 8｜5/15（六）奥州全馬報到
- **奥州閃耀馬拉松 報到 / 領號碼布**（會場：奥州市江刺総合支所）
- 賽前 briefing、早瞓
- 🏨 宿：奥州/一関（步行/短途到會場最佳）

### Day 9｜5/16（日）🏅 岩手奧州閃耀馬拉松（42.195km）
- **8:30 起跑**，限時 6:00（6 個關門點）
- 賽道：奥州市江刺総合支所出發，高低差僅 20m **全平緩賽道，破PB絕佳**
- 完賽：慶功、前澤牛慶祝、花卷溫泉恢復
- 🏨 宿：奥州/仙台

### Day 10｜5/17（一）仙台 → 香港
- 朝早：秋保温泉/仙台市內慢逛
- **SDJ → HKG 返港**（跑完全馬休息足一日先飛）

## 四、馬拉松相關注意事項 ⚠️

### 1. 半馬 + 全馬 相隔 7 日（最重要！）
- 5/9 半馬 + 5/16 全馬係「背靠背」double challenge
- **建議**：仙台半馬用**控制配速**跑（當高質素 long run / tempo，唔好搏 PB），主力放晒喺奥州全馬
- 中間一星期：**減量（taper）+ 恢復**，只做輕鬆跑/完全休息，唔好加量

### 2. 賽事報名（有經驗人仕幫手）
- **仙台半馬**：經 runnet 報名，報名期約 **2026年12月**；需提交達標紀錄（一般I：半馬<2:00 或 全馬<4:30；一般II：能 2:30 內完成半馬）；參賽費 ¥8,000
- **奥州閃耀馬拉松**：經 RUNNET/郵便，報名期約 **2026年11月底–2027年2月中**；全馬 ¥10,000；定員 3,000 人
- 👉 唔保證名額、唔代辦 —— 但有**有經驗人仕**陪你報名、跟進流程，唔使自己盲摸摸

### 3. 號碼布領取（一定要賽前一日）
- 仙台半馬：**5/8（六）** 會場領取
- 奥州全馬：**5/15（六）** 會場領取（無郵寄）
- 所以要預留 Day 1 / Day 8 下午去報到

### 4. 住宿要早訂
- 賽前週六（5/9、5/16 前一晚）大城市/賽事區酒店緊張（東横INN 等都會爆滿）
- 建議一確認報名成功就訂，尤其仙台駅周邊同奥州/一関

### 5. 交通（JR Pass 全包）
- **仙台→一ノ関**：新幹線 ~45min
- **奥州會場**：最近站 水沢江刺（JR東北本線）；賽日有**免費穿梭巴士**
- **東北 JR Pass 10日 ¥50,000**：5/8–5/17 連續使用，東北新幹線+在來線任搭，夾埋三陸鐵道，回本無難度

### 6. 天氣 & 裝備
- 5月東北：日間約 15–22°C，全馬可能偏暖 —— 帶**防曬、帽子、補給**，注意補水
- 半馬全馬都係官方補給，但可自備能量膠
- 跑鞋：兩場共用一對比賽鞋就得（相隔 7 日夠回復）

### 7. 全馬後恢復
- **唔好即日飛** —— 跑完 42km 之後搭長途機好辛苦，休息一晚（Day 10）先走
- 花卷溫泉/秋保溫泉 泡湯、按摩、食牛

### 8. 額外彩蛋：東京馬拉松2027抽籤
- 仙台半馬係 **RUN as ONE – Tokyo Marathon 2027** 提攜大會 —— 完賽者可申請抽 **3 個東京馬拉松 2027 出走名額**
- 參加 package 等於多一個「衝六大」嘅機會
